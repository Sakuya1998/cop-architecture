# Standards Index

## 分类目的

统一全仓库术语、文档格式、状态、链接、图表和评审规则，保持跨文档一致性。

| ID | Document | Priority | Status | Purpose |
| --- | --- | --- | --- | --- |
| COP-STD-001 | [COP Terminology](terminology.md) | P0 | draft | 建立全仓库统一语言并禁止 Resource、Asset、Metadata、CMDB 等概念随意混用。 |
| COP-STD-002 | [COP Documentation Standard](documentation-standard.md) | P2 | draft | 固化文档元数据、状态、章节、链接、图表、评审和演进规则。 |

## 推荐阅读顺序

1. COP-STD-001 COP Terminology
2. COP-STD-002 COP Documentation Standard

只有 `status: accepted` 的文档具有实现权威；`draft` 和 `review` 文档仅用于讨论与设计收敛。
