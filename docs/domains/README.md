# Domains Index

| ID | Document | Priority | Status | Purpose |
| --- | --- | --- | --- | --- |

| COP-DOM-002 | [COP IAM Domain](iam-domain.md) | P1 | draft | 定义身份、主体、组织、租户和访问管理领域。 |
| COP-DOM-003 | [COP Resource Metadata Domain](resource-metadata-domain.md) | P1 | draft | 定义 Resource、Resource Type、Attribute、Relationship 和 CMDB 语义。 |
| COP-DOM-004 | [COP Cloud Access Domain](cloud-access-domain.md) | P1 | draft | 定义云账号、凭据引用、Provider、资源发现和同步边界。 |
| COP-DOM-005 | [COP Observability Domain](observability-domain.md) | P1 | draft | 定义遥测接入、信号类型、查询边界和资源关联。 |
| COP-DOM-006 | [COP Alerting Domain](alerting-domain.md) | P1 | draft | 定义告警规则、评估结果、告警实例、状态和通知关系。 |
