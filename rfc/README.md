# RFC Index

## RFC 目的

RFC 用于记录重大架构变更的背景、目标、备选方案、影响、迁移和评审过程。RFC 不直接替代当前状态的权威文档。

文件名规则：`RFC-0001-topic.md`。

状态流：`draft → review → accepted/rejected → superseded`。

接受流程：`accepted RFC → linked ADR → authoritative document updates`。接受 RFC 后必须关联 ADR，并同步更新所有受影响的权威文档。

新 RFC 请使用 [RFC Template](../templates/rfc-template.md)。
