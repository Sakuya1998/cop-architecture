# ADR Index

## ADR 目的

ADR 用于记录已经作出的架构决策、选择理由、后果和关联资料，提供可追踪的决策历史。

文件名规则：`ADR-0001-decision.md`。

状态流：`proposed → accepted → deprecated/superseded`。

ADR 解释决策，但不替代描述当前状态的权威文档；决策接受后必须在受影响的权威文档中反映当前有效内容。

新 ADR 请使用 [ADR Template](../templates/adr-template.md)。
